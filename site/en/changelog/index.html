01Conversation

An AI tab
inside PoB.

No copying numbers into another app. The conversation sits next to the build you already have open.

01

Integrated AI tab

A new AI item opens the chat inside the normal Path of Building interface.

02

Open questions

Type a question about the character, send it with Enter, and continue the conversation in the same session.

03

Responsive while waiting

The request runs in the background and the text appears progressively while PoB remains responsive.

04

Ready-made prompts

Buttons to start with the best next upgrade, build weaknesses, or the best support gem.

05

Session history

Recent messages stay in the chat while PoB is open, so follow-up questions retain their context.

06

Visible status

The panel shows when it is preparing the build, waiting for AI, receiving the answer, or validating a suggestion.

02Build understanding

AI reads what
actually matters.

Its context comes from the open build and the numbers already calculated by PoB.

01

Character

Class, ascendancy, level, bandit choice, pantheon, and main skill.

02

Damage and defence

DPS, EHP, life, mana, energy shield, resistances, mitigation, and Max Hit by damage type.

03

Gems and skills

Skill groups, active gems, supports, levels, quality, and which group is the main one.

04

Gear

Equipped items, slots, modifiers, and jewels used by the current character.

05

Passive tree

Starting class, ascendancy, allocated passives, masteries, tattoos, jewels, and available points.

06

Calculation settings

Conditions selected in the Configuration tab that affect the build's result.

07

Selective context

The question determines which extra details are needed. Gems, uniques, the tree, and configuration are expanded only when they help, rather than sending everything every time.

03Tests in the real engine

Suggestions with
calculated results.

When a question calls for a comparison, V1 uses PoB itself to measure the candidates.

01

Support gems

Tests compatible supports in the main skill and ranks their real DPS gains.

02

Unique items

Compares a selection of uniques in valid slots and shows their impact on DPS, EHP, and Max Hit.

03

Next passives

Shows reachable notables and keystones within the available points to help guide the next choice.

04

Details on demand

When an answer mentions a gem, unique, or passive, the bridge can load the exact data for that element before finishing.

05

The original build stays untouched

Comparisons run in temporary copies. The open character remains intact during analysis.

06

One context expansion

If a good answer needs more data, AI can request one extra set of information without entering an endless loop.

05You decide

Preview first.
Apply second.

An AI answer never becomes an automatic change to the character.

01

Restricted format

Every suggestion must be one of the 18 accepted actions with the correct fields. Unknown actions are rejected.

02

Tested in a copy

The entire batch is first applied to an isolated clone of the build and recalculated by the PoB engine.

03

Real before and after

The preview shows calculated differences in DPS, EHP, Max Hit, life, resistances, points, and other affected numbers.

04

The full batch or nothing

If one change fails, the preview is rejected. V1 does not present a partial result as though it were complete.

05

Stale preview protection

If you edit the build after calculation, Apply is blocked and the suggestion must be tested again.

06

Deliberate Apply

Only the Apply button changes the real build. The app also reports which actions were applied and which failed.

06Your AI, your key

Local setup
with no middleman.

The project does not sell an AI service. You choose the connection you want to use.

01

Integrated AI Setup

A popup inside PoB accepts the API key, HTTPS endpoint, and model name.

02

OpenAI-compatible format

Works with services that provide an OpenAI-format API, without locking you into a single provider.

03

Connection test

The Test button verifies the key, endpoint, and model before you save the configuration.

04

Masked and local key

The field hides the key and its configuration file stays in the user data folder, outside the repository and download.

05

HTTPS required

Insecure endpoints are rejected. Connection and total request timeouts are also enforced.

06

No project server

PathOfAIBuilding has no proxy, telemetry, or analytics. The conversation goes directly from your computer to the service you chose.

What the AI service receives

Your question, recent history, and the parts of the build required for the answer. The key is used only in the authorisation header. Choose a service you trust.

08Honest scope

What V1
does not do yet.

The first release is focused on reviewing and improving an existing build.

—

It does not create a complete build from scratch

You need to open an existing character before starting the conversation.

—

It does not check prices or execute trades

V1 makes no promise about budgets, current prices, or automatically buying items.

—

It does not optimise the whole tree on its own

It can guide nearby passives and apply proposed changes, but it does not solve the entire tree automatically.

—

Shortlists are not exhaustive catalogues

Gem and unique comparisons use relevant candidates, not every possible combination in the game.

—

AI can still be wrong

PoB checks the numbers and the preview reduces risk, but you remain responsible for reviewing the suggestion.

—

Your AI service may charge

The app is free; API costs, usage limits, and privacy depend on the service you configure.
